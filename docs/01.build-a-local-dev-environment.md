# ローカル開発環境の構築

## 目的

Codeigniter4のアプリケーションの開発を安全に行うためのローカル環境を構築する。

## 要件

### アプリケーションの構成

以下のホストで構成する

- nginx
- PHP8.4 fpm
- MySQL8

### 外部連携

PHPアプリケーションでは以下の外部連携があり、これらはの連携はdocker仮想環境内のスタブサーバーで受け、外部に影響しないようにする。

web(nginx)以外のコンテナンの network を `internal: true` と設定することによりこれを実現する。

ホストPCからWebUIにアクセスしたい場合など port を指定してWebUIのみ見られるようにする。

- FTP
- S3
- メール

## 使用するコンテナイメージ

PHPアプリケーションから各外部連携が行われるが、はdockerネットワークを `internal: true` とし、外部にアクセスしないようにする。

その他のコンテナについてもネットワークは `internal：true` とし、WebUIにアクセスする必要があるものは port で指定する。

### FTPサーバー代替

stilliard/pure-ftpd を使用する。

ローカルディレクトリにマウントし、FTPアップロードされるファイルを直接ホストPCから編集できるようにする。

### S3代替

RustFS を使用する。

MinIOはdockerイメージの提供をやめたため。

portを指定してWebUIをホストPCに公開する。

### メールサーバー代替

Mailpit を使用する。

リレー機能を明示的に無効化する。

portを指定してWebUIをホストPCに公開する。
