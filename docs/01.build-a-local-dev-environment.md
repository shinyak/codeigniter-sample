# ローカル開発環境の構築

## 目的

Codeigniter4のアプリケーションの開発を安全に行うためのローカル環境を構築する。

## 要件

### アプリケーションの構成

以下のホストで構成する

- nginx
- PHP8.4 fpm
- MySQL8

### 外部連携

以下の外部連携があり、これらはの連携はdocker仮想環境内のスタブサーバーで受け、外部に影響しないようにする。

docker network の `internal: true` 設定によりこれを実現する。

- FTP
- S3
- メール

## 使用するコンテナイメージ

PHPアプリケーションから各外部連携が行われるが、PHPコンテナはdockerネットワークを `internal: true` とし、外部にアクセスしないようにする。

### FTPサーバー代替

stilliard/pure-ftpd を使用する。

### S3代替

RustFS を使用する。

MinIOはdockerイメージの提供をやめたため。

### メールサーバー代替

Mailpit を使用する。
