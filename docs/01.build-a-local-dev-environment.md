# ローカル開発環境の構築

## 目的

Codeigniter4のアプリケーションの開発を安全に行うためのローカル環境を構築する。

## 要件

### アプリケーションの構成

以下のホストで構成する

- nginx
- PHP8.4 fpm
- MySQL8

### 外部連携

PHPアプリケーションでは以下の外部連携があり、これらはの連携はdocker仮想環境内のスタブサーバーで受け、外部に影響しないようにする。

PHPコンテナンの network を `internal: true` と設定することによりこれを実現する。

- FTP
- S3
- メール

## 使用するコンテナイメージ

PHPアプリケーションから各外部連携が行われるが、PHPコンテナはdockerネットワークを `internal: true` とし、外部にアクセスしないようにする。

### FTPサーバー代替

stilliard/pure-ftpd を使用する。

ローカルディレクトリにマウントし、FTPアップロードされるファイルを直接ホストPCから編集できるようにする。

### S3代替

RustFS を使用する。

MinIOはdockerイメージの提供をやめたため。

### メールサーバー代替

Mailpit を使用する。

リレー機能を明示的に無効化する。

## RustFS(S3代替) の導入

`docker-compose.yml` に `rustfs` サービスを追加し、`private` ネットワーク内で S3 互換 API を提供する。

- API endpoint: `http://rustfs:9000`
- Console endpoint: `http://rustfs:9001`（コンテナ内のみ）
- Access Key: `${S3_ACCESS_KEY:-rustfsadmin}`
- Secret Key: `${S3_SECRET_KEY:-rustfsadmin}`
- 永続データ: `./docker/rustfs/data`, `./docker/rustfs/logs`

起動:

```bash
docker compose up -d --build rustfs
```

疎通確認:

```bash
docker compose exec php php -r '$s=@fsockopen("rustfs",9000,$e,$m,5); echo $s?"OK\n":"NG ($e $m)\n"; if($s) fclose($s);'
```
