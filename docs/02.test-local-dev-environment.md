# ローカル開発環境の疎通確認

## 目的

`docker-compose.yml` で起動したローカル開発環境について、以下 4 サーバーの疎通を確認する。

- web (`nginx`)
- php (`php-fpm`)
- mysql
- ftp

確認観点は次の 2 つ。

- PHP サーバー（`php` コンテナ）からの疎通
- コンテナから外部へ出られないこと（`private: internal: true`）

## 前提

1. コンテナを起動済みであること

```bash
docker compose up -d --build
```

2. 稼働状態を確認する

```bash
docker compose ps
```

`php` / `nginx` / `mysql` / `ftp` が `Up` であること。

## 1. PHP サーバーからの疎通確認

`php` コンテナ内から各サービスのポートへ TCP 接続を試す。

```bash
docker compose exec php php -r 'foreach (["nginx:80","php:9000","mysql:3306","ftp:21"] as $target) { [$host,$port]=explode(":",$target); $sock=@fsockopen($host,(int)$port,$errno,$errstr,3); echo $target." => ".($sock?"OK":"NG ({$errno} {$errstr})").PHP_EOL; if ($sock) fclose($sock); }'
```

期待結果:

- `nginx:80 => OK`
- `php:9000 => OK`
- `mysql:3306 => OK`
- `ftp:21 => OK`

補足:

- 同一 Docker ネットワーク（`private`）内の名前解決で到達できることを確認している。

## 2. コンテナから外部へ出られないことの確認

`php` コンテナ内から外部宛て通信を試し、失敗することを確認する。

```bash
docker compose exec php php -r '$s=@fsockopen("example.com",443,$e,$m,5); echo $s?"OK\n":"NG ($e $m)\n"; if($s) fclose($s);'
```

期待結果:

- `NG (...)` が表示される。

あわせて TCP レベルでも失敗することを確認する。

```bash
docker compose exec php php -r '$s=@fsockopen("1.1.1.1",443,$e,$m,5); echo $s?"OK\n":"NG ($e $m)\n"; if($s) fclose($s);'
```

期待結果:

- `NG (...)` が表示される。

## 判定基準

- PHP コンテナから 4 サービスすべて `OK` なら、コンテナ間疎通は正常。
- PHP コンテナから外部宛て通信が失敗すれば、`internal: true` による外部遮断（egress制御）は正常。

## トラブルシュート

- `docker compose ps` で `Up` でない場合は、対象コンテナのログを確認する。

```bash
docker compose logs php
docker compose logs nginx
docker compose logs mysql
docker compose logs ftp
```
