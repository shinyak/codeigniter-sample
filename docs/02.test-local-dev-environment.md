# ローカル開発環境の疎通確認

## 目的

`docker-compose.yml` で起動したローカル開発環境について、以下 4 サーバーの疎通を確認する。

- web (`nginx`)
- php (`php-fpm`)
- mysql
- ftp

確認観点は次の 3 つ。

- 各コンテナ（`php` / `mysql` / `ftp`）の基本動作
- PHP サーバー（`php` コンテナ）からの疎通
- コンテナから外部へ出られないこと（`private: internal: true`）

## 前提

1. コンテナを起動済みであること

```bash
docker compose up -d --build
```

2. 稼働状態を確認する

```bash
docker compose ps
```

`php` / `nginx` / `mysql` / `ftp` が `Up` であること。

## 1. 各コンテナの基本動作確認

### phpコンテナ

PHP CLI が起動できることを確認する。

```bash
docker compose exec php php -v | head -n 1
```

期待結果:

- `PHP 8.x.x ...` が表示される。

### mysqlコンテナ

`ci4` DB に接続して SQL を実行できることを確認する。

```bash
docker compose exec mysql mysql -D ci4 -u ci4 -pci4secret -e "show tables"
```

期待結果:

- `migrations` などテーブル一覧が表示される。

### ftpコンテナ

FTP サーバープロセスの待受ポートへ接続できることを確認する。

```bash
docker compose exec ftp bash -lc 'timeout 5 bash -lc "cat < /dev/null > /dev/tcp/127.0.0.1/21" && echo OK || echo NG'
```

期待結果:

- `OK` が表示される。

## 2. PHP サーバーからの疎通確認

`php` コンテナ内から各サービスのポートへ TCP 接続を試す。

```bash
docker compose exec php php -r 'foreach (["nginx:80","php:9000","mysql:3306","ftp:21"] as $target) { [$host,$port]=explode(":",$target); $sock=@fsockopen($host,(int)$port,$errno,$errstr,3); echo $target." => ".($sock?"OK":"NG ({$errno} {$errstr})").PHP_EOL; if ($sock) fclose($sock); }'
```

期待結果:

- `nginx:80 => OK`
- `php:9000 => OK`
- `mysql:3306 => OK`
- `ftp:21 => OK`

補足:

- 同一 Docker ネットワーク（`private`）内の名前解決で到達できることを確認している。

### phpコンテナからmysqlサーバーを利用できることの確認

`php` コンテナから `mysqli` で `mysql` に接続し、SQL を実行できることを確認する。

```bash
docker compose exec php php -r '$db=new mysqli("mysql","ci4","ci4secret","ci4",3306); if($db->connect_error){echo "NG {$db->connect_errno} {$db->connect_error}\n"; exit(1);} $res=$db->query("SHOW TABLES"); echo $res?"OK\n":"NG query\n"; if($res){while($r=$res->fetch_row()){echo $r[0]."\n";}} $db->close();'
```

期待結果:

- `OK` が表示される。
- `migrations` などテーブル名が表示される。

### phpコンテナからftpサーバーを利用できることの確認

`php` コンテナから `ftp` へ接続し、`USER/PASS/PWD` の応答を確認する。

```bash
docker compose exec php php -r 'function ftpRead($fp){$line=""; while(($l=fgets($fp))!==false){$line=$l; if(preg_match("/^\\d{3} /",$l)) break;} return trim($line);} $fp=@fsockopen("ftp",21,$e,$m,5); if(!$fp){echo "NG connect ($e $m)\n"; exit(1);} stream_set_timeout($fp,5); $b=ftpRead($fp); fwrite($fp,"USER testftp\r\n"); $u=ftpRead($fp); fwrite($fp,"PASS testftp\r\n"); $p=ftpRead($fp); fwrite($fp,"PWD\r\n"); $w=ftpRead($fp); fwrite($fp,"QUIT\r\n"); ftpRead($fp); $ok=(strpos($b,"220 ")===0 && strpos($u,"331 ")===0 && strpos($p,"230 ")===0 && strpos($w,"257 ")===0); echo $ok?"OK\n":"NG\n"; echo $u."\n".$p."\n".$w."\n"; fclose($fp);'
```

期待結果:

- `OK` が表示される。
- `331 ...` / `230 ...` / `257 ...` が表示される。

## 3. コンテナから外部へ出られないことの確認

### phpコンテナの外部遮断確認

`php` コンテナ内から外部宛て通信を試し、失敗することを確認する。

```bash
docker compose exec php php -r '$s=@fsockopen("example.com",443,$e,$m,5); echo $s?"Connected\n":"Blocking ($e $m)\n"; if($s) fclose($s);'
```

期待結果:

- `Blocking (...)` が表示される。
- 例: `Blocking (0 php_network_getaddresses: getaddrinfo ... failed)`。

あわせて TCP レベルでも失敗することを確認する。

```bash
docker compose exec php php -r '$s=@fsockopen("1.1.1.1",443,$e,$m,5); echo $s?"Connected\n":"Blocking ($e $m)\n"; if($s) fclose($s);'
```

期待結果:

- `Blocking (...)` が表示される。
- 例: `Blocking (110 Connection timed out)`。

### mysqlコンテナの外部遮断確認

`mysql` コンテナ内から外部宛て TCP 接続を試し、失敗することを確認する。

```bash
docker compose exec mysql bash -lc 'timeout 5 bash -lc "cat < /dev/null > /dev/tcp/example.com/443" && echo Connected || echo Blocking'
```

期待結果:

- `Blocking` が表示される。

あわせて IP 直指定でも失敗することを確認する。

```bash
docker compose exec mysql bash -lc 'timeout 5 bash -lc "cat < /dev/null > /dev/tcp/1.1.1.1/443" && echo Connected || echo Blocking'
```

期待結果:

- `Blocking` が表示される。

### ftpコンテナの外部遮断確認

`ftp` コンテナ内から外部宛て TCP 接続を試し、失敗することを確認する。

```bash
docker compose exec ftp bash -lc 'timeout 5 bash -lc "cat < /dev/null > /dev/tcp/example.com/443" && echo Connected || echo Blocking'
```

期待結果:

- `Blocking` が表示される。

あわせて IP 直指定でも失敗することを確認する。

```bash
docker compose exec ftp bash -lc 'timeout 5 bash -lc "cat < /dev/null > /dev/tcp/1.1.1.1/443" && echo Connected || echo Blocking'
```

期待結果:

- `Blocking` が表示される。

## 判定基準

- PHP コンテナから 4 サービスすべて `OK` なら、コンテナ間疎通は正常。
- PHP コンテナからの `mysql` 利用確認（`SHOW TABLES`）と `ftp` 利用確認（`USER/PASS/PWD` 応答確認）が成功していること。
- `php` / `mysql` / `ftp` の基本動作確認がすべて成功していること。
- `php` / `mysql` / `ftp` の各コンテナから外部宛て通信が失敗すれば、`internal: true` による外部遮断（egress制御）は正常。
